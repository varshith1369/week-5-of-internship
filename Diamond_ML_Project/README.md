# Diamond Price Prediction - ML Pipeline

## Overview
This repository contains the Python machine learning pipeline implementing a Random Forest Regressor on the classic seaborn/scikit-learn `diamonds` dataset for the Week 5 Machine Learning task.

## Files Included
- `train_diamonds_model.py`: Full end-to-end Python script containing preprocessing, pipeline creation, randomized hyperparameter tuning, model evaluation metrics, and visualization generation.
- `Diamond_ML_Workflow_Report.docx`: Detailed Word document report covering algorithm justification, pre-processing steps, hyperparameter tuning, and evaluation results.
- `requirements.txt`: Required dependencies (`pandas`, `numpy`, `scikit-learn`, `seaborn`, `matplotlib`, `python-docx`).

## Running the Code
1. Install dependencies:
   ```bash
   pip install pandas numpy scikit-learn seaborn matplotlib python-docx
   ```
2. Run the training script:
   ```bash
   python train_diamonds_model.py
   ```
